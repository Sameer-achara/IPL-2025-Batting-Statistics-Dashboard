# 🏏 IPL 2025 Analytics Dashboard

A dynamic, interactive, and production-ready web application built using **Streamlit** and Python's powerful data science libraries (**Pandas, Seaborn, Matplotlib**) to analyze player and team performances in IPL 2025.

---

## 🌟 Key Features

- **👑 Live Metric Cards:** Displays global tournament highlights instantly—Orange Cap Leader, Highest Strike Rate (min. 100 balls), and Highest Individual Score.
- **🗂️ 3-Tab Optimized Layout:** Streamlines data visualization into clean tabs to avoid endless scrolling:
  - `🏏 Batting Leaderboards`: Top run-scorers, consistent batters, aggressive players, boundary kings, and century hitters.
  - `📊 Team Performance`: Team-wise total runs share (Pie Chart), top-scorers, average strike rates, and total boundaries.
  - `🔍 Player Search Profile`: Dedicated lookup window to pull up complete real-time stats for any individual player.
- **🎛️ Linked Sidebar Filters:** Smooth navigation allowing users to filter the entire dataset by specific teams. The player search dropdown dynamically updates based on the selected team!
- **🎨 Premium Visuals:** Center-aligned stylized title components, custom palettes (`flare`, `magma`, `crest`), and clean `st.divider()` sections for an industry-grade UX.

---

## 🛠️ Tech Stack & Dependencies

This project relies on the following open-source Python libraries:
- **Streamlit** (Frontend Web Framework)
- **Pandas** (Data Manipulation & Aggregation)
- **NumPy** (Numerical Computing)
- **Matplotlib** (Core Visualization Engine)
- **Seaborn** (Advanced Statistical Data Visualization)
